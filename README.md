# scoop-bucket

[![Tests](https://github.com/fanlusky/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/fanlusky/scoop-bucket/actions/workflows/ci.yml) [![Excavator](https://github.com/fanlusky/scoop-bucket/actions/workflows/excavator.yml/badge.svg)](https://github.com/fanlusky/scoop-bucket/actions/workflows/excavator.yml)

A [Scoop](https://scoop.sh) bucket for fanlusky's apps.

| App | Description |
| --- | --- |
| [ndx](https://github.com/fanlusky/Ndx) | Native Windows GUI client for Neovim |

## Usage

```pwsh
scoop bucket add fanlusky https://github.com/fanlusky/scoop-bucket
scoop install fanlusky/ndx
```
